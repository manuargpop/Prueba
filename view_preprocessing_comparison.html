📱 Preprocessing Comparison for Phone-Captured Cedulas

Analysis & Recommendations

Problem: The current pipeline uses a 5×5 Gaussian blur which can be too strong for already-blurry phone images, making text harder to read for EasyOCR.

💡 Best Approaches for Phone Images:

  1. Adaptive Thresholding (Variant 07-08): Best for OCR text extraction - converts to high-contrast black/white text
  2. CLAHE Enhancement (Variant 05-06): Improves contrast without losing detail, great for uneven lighting
  3. Sharpening Filter (Variant 04): Counteracts blur from phone cameras
  4. Weaker Blur (Variant 03): Use 3×3 instead of 5×5 if keeping current pipeline

My Recommendation: For your use case with phone photos, I suggest using Variant 07 (Adaptive Threshold) or Variant 05 (CLAHE) before passing to EasyOCR. These preserve text clarity while reducing noise.
